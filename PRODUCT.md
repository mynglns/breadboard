# Product context

## Product

LED Flasher / Interactive Build is a small, public-facing 3D explainer for a 5 V two-transistor LED flasher assembled on a breadboard.

## Visitor outcome

Open one URL and inspect the supplied breadboard model immediately, without downloading a file or navigating an information-heavy interface.

## Surface mode

Experience. The model is the whole page; orbit and zoom are the only required interaction.

## Constraints

- Use the supplied GLB as the source of truth for the 3D scene.
- Keep the site static so it can publish cleanly through GitHub Pages.
- Do not require a manual download for visitors.
- Keep interface chrome to a single reset action and a short interaction hint.
