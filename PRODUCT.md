# Product context

## Product

LED Flasher / Interactive Build is a small, public-facing 3D explainer for a 5 V two-transistor LED flasher assembled on a breadboard.

## Visitor outcome

Within one viewport, a first-time visitor should understand that the build is a physical circuit, see the alternating LED behavior, and be able to inspect the six parts that make the feedback loop work.

## Surface mode

Experience + operate. The model leads; controls and component inspection make the mechanism legible without turning the page into a documentation wall.

## Constraints

- Use the supplied GLB as the source of truth for the 3D scene.
- Keep the site static so it can publish cleanly through GitHub Pages.
- Avoid invented electrical claims beyond the visible 5 V / astable context.
- Make primary model actions usable with pointer, touch, and keyboard focusable controls.
